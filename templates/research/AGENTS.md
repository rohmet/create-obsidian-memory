## Instruksi untuk AI Agent

**Setiap memulai sesi, kamu HARUS:**
1. Baca `.memory/progress.md` → status bab & milestone terkini
2. Baca `.memory/sessions/` terbaru → konteks sesi sebelumnya
3. Baca `.memory/research.md` → detail RQ dan metodologi
4. Baca `.memory/findings.md` → temuan yang sudah ada
5. Baru bantu kerjakan task yang diminta

**Setiap selesai sesi, kamu HARUS:**
1. Update `.memory/progress.md` jika ada bab yang statusnya berubah
2. Update `.memory/findings.md` jika ada temuan baru
3. Buat `.memory/sessions/YYYY-MM-DD.md` berisi log sesi
4. Buat `.memory/decisions/RDC-XXX.md` jika ada keputusan metodologis besar

**Hal yang TIDAK boleh dilakukan:**
- ❌ Jangan fabricate / generate data penelitian palsu
- ❌ Jangan ubah coding / tema kualitatif tanpa konfirmasi
- ❌ Jangan edit file `sessions/` yang sudah ada — buat file baru
- ❌ Jangan simpulkan sesuatu yang melampaui data yang ada
