# create-obsidian-memory

> **CLI Tool resmi untuk membuat structured Obsidian-based persistent AI memory templates.**

Memudahkan pembuatan base memory untuk AI Agent (Cursor, Claude Code, Gemini Antigravity, Windsurf, dll) hanya dengan 1 perintah `npx`.

---

## 🚀 Cara Penggunaan

Cukup jalankan perintah ini di terminal kamu:

```bash
npx create-obsidian-memory
```

Atau tentukan langsung direktori tujuan:

```bash
npx create-obsidian-memory my-new-project
```

---

## 📦 Template Yang Tersedia

1. **🌐 Web Project Memory**
   * Untuk pengembangan aplikasi web/software (vibe coding, Next.js, fullstack).
   * Melacak arsitektur, progress fitur, API routes, dan keputusan desain.

2. **🔬 Research Memory**
   * Untuk skripsi S1, tesis S2, maupun paper ilmiah (kuantitatif, kualitatif, mixed-methods).
   * Melacak status bab, peta literatur, metodologi, dan catatan bimbingan.

3. **📝 Theory Assignment Memory**
   * Untuk tugas esai, kajian teori, atau tinjauan literatur non-empiris.
   * Melacak argumen orisinal, perdebatan konsep, dan outline esai.

4. **💼 Career Memory**
   * Untuk identitas profesional, CV, portofolio, dan lamaran kerja.
   * Membimbing AI dalam generate CV & cover letter tailored secara otomatis berdasarkan job description.
